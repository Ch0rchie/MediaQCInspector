# Media QC Inspector

## Brand Guidelines v1.0

**Version:** 1.0  
**Date:** July 2026

> **Validate. Inspect. Deliver.**

---

# 1. Brand Mission

Media QC Inspector is a professional desktop application for media quality control and technical reporting. The product emphasizes confidence, precision, and clarity throughout the inspection workflow.

---

# 2. Brand Personality

The application should feel:

- Professional
- Precise
- Trustworthy
- Modern
- Clean
- Confident

Avoid visual styles that feel playful, flashy, futuristic, medical, or entertainment-oriented.

---

# 3. Brand Voice

Writing should be:

- Objective
- Concise
- Technical where appropriate
- Easy to understand
- Actionable

Reports should explain:

1. What was detected.
2. Where it occurred.
3. Why it matters.
4. Recommended next steps.

---

# 4. Product Name

Official product name:

**Media QC Inspector**

Do not abbreviate in user-facing materials.

---

# 5. Tagline

**Validate. Inspect. Deliver.**

Always retain the periods.

---

# 6. Logo & Icon

The icon consists of:

- Blue rounded-square background
- Media display frame
- Magnifying glass
- Checkmark integrated inside the lens

The icon represents **inspection and validation**, not a specific media format.

---

# 7. Color Palette

Primary Blue: #1F73FF

Deep Navy: #081A3D

Display Blue: #0D2F73

White: #FFFFFF

Success Green: Reserved for PASS status only.

---

# 8. Typography

Primary:
- SF Pro Display (macOS)

Fallback:
- Helvetica Neue

---

# 9. Design Principles

Every design decision should reinforce:

- Confidence
- Clarity
- Precision
- Consistency
- Simplicity

---

# 10. Launch Experience

## Duration

Target: 1.8–2.2 seconds

Display only when startup requires noticeable initialization.

## Animation Sequence

1. Dark navy background.
2. Soft blue scanning light sweeps across the screen.
3. Media frame fades in.
4. Magnifying glass appears with a subtle scale transition.
5. Checkmark fades into the lens.
6. "Media QC Inspector" fades in.
7. The tagline appears one word at a time:

- Validate.
- Inspect.
- Deliver.

8. Brief pause.
9. Transition into the application.

No sound effects.

Animations should feel calm, elegant, and purposeful.

---

# 11. Reports

Use consistent status colors:

- PASS — Green
- WARNING — Orange
- FAIL — Red

Reports should remain clean, readable, and production-oriented.

---

# 12. GitHub

Use a 1280×640 social preview featuring:

- Product icon
- Product name
- Tagline
- Professional media QC messaging

---

# 13. About Window

Display:

- Application icon
- Product name
- Version / Build
- Status
- Created by David L. Gelb

---

# 14. Future Branding

Future assets should follow these guidelines:

- Splash screen
- DMG installer
- Website
- Documentation
- Windows version
- Training material

Maintain one consistent visual identity across every platform.

---

# Brand Philosophy

Media QC Inspector should inspire confidence before a user analyzes a single file.

Every interaction should reinforce the product's mission:

**Validate. Inspect. Deliver.**
