# Media QC Inspector

Version 0.3.0

Media QC Inspector is a macOS application for validating Apple ProRes media files by detecting decoder errors, extracting technical metadata, and generating professional Technical Validation Reports for production workflows.

## Features

- FFmpeg-based decoder validation
- Metadata extraction
- Technical Validation Reports
- Error localization
- Editorial review windows
- Drag-and-drop queue
- Copy report

## Requirements

- macOS
- FFmpeg / FFprobe
